# Thank's

## How

Fork, create branch then create pull request.
example:

1. `git checkout -b update`
2. make change on that branch, specialy on `dist` folder
3. `git add .` then commit
4. `git push origin update`
5. wait my approval
6. after merged, delete `update`
7. `git checkout main` -> `git branch -D update` -> `git push origin --delete update`
